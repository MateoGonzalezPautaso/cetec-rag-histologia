Demo

El sistema en acción sobre el manual de histología de la cátedra.

Búsqueda de imágenes del manual

El usuario pide imágenes de un tema y el asistente las recupera con su descripción y fuente citada.

Análisis multimodal

El usuario sube una foto de una preparación al microscopio; el sistema la identifica comparándola contra las imágenes de referencia del manual.

Características

Un pipeline RAG completo, no un wrapper de chatbot.

🗣️

Respuestas citadas

Cada respuesta incluye la fuente exacta del manual (archivo y página), con trazabilidad completa.

🖼️

Multimodal

Subí una imagen histológica y preguntá sobre ella. El sistema la analiza con modelos de visión especializados en patología (UNI y PLIP).

🔬

Comparación imagen↔manual

Compara la imagen del usuario contra las imágenes de referencia del manual para identificar la estructura histológica.

🔎

Búsqueda híbrida

Combina similitud semántica de texto, entidades histológicas, keywords y embeddings visuales en una sola búsqueda ponderada.

🧭

Clasificador de dominio

Descarta consultas fuera de histología antes de consumir retrieval o cuota de LLM, con árbitro LLM en casos ambiguos.

🧠

Memoria por sesión

Recuerda el historial y la imagen activa entre turnos del chat, aislada por usuario. La imagen persiste hasta que el usuario la cambie.

📊

Evaluación cuantitativa

Pipeline RAGAS completo (fidelidad, relevancia, recall de contexto) + smoke tests de confiabilidad automatizados.

💻

Local-first

Qdrant embebido por defecto — sin servicios externos ni Docker. Funciona en CPU; GPU NVIDIA acelera los modelos de visión.

Cómo funciona

Cada consulta recorre un grafo de estados LangGraph con bifurcación según imagen y dominio.

→

→

→

→

→

→

Respuesta citada

La búsqueda híbrida en buscar_qdrant combina cinco señales: vectorial de texto (MiniLM), embeddings visuales UNI + PLIP, búsqueda por entidades histológicas (payload de Qdrant) y fallback por keywords. Los pesos cambian según si hay imagen activa o no.

Stack tecnológico

Tecnologías de producción, sin dependencias de nube obligatorias.

FastAPI

Backend REST + frontend servido same-origin

LangGraph

Orquestador de estados del pipeline RAG

Qdrant

Base vectorial embebida con named vectors

Llama 4 Scout (Groq)

LLM generador y árbitro de clasificación

UNI (MahmoodLab)

ViT-L patología, 1024d — embedding visual principal

PLIP (vinid)

CLIP fine-tuned en patología, 512d

MiniLM-L6-v2

Embeddings de texto, 384d

PyMuPDF + Tesseract

Extracción de texto e imágenes de PDFs

Inicio rápido

Desde cero hasta el servidor corriendo en cuatro pasos.

1

Clonar el repositorio

git clone https://github.com/MateoGonzalezPautaso/cetec-rag-histologia.git
cd cetec-rag-histologia
2

Crear el archivo de dependencias

# pyproject.toml no está versionado (depende de CPU/GPU)
cp app/pyproject.example.toml app/pyproject.toml
3

Configurar las claves de API

cp .env.example app/.env
# Editar app/.env con GROQ_API_KEY y HF_TOKEN
4

Lanzar el servidor

cd app && ./start.sh
# Abre automáticamente http://localhost:10007
